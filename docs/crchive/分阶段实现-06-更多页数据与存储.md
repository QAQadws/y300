# 分阶段实现 06：更多页“数据与存储”

本阶段目标是替换旧的“缓存目录”入口，新增“数据与存储”页面，集中管理图片缓存清理、图片缓存上限、下载存储位置。

## 目标

1. 删除“更多”页中的“缓存目录”菜单。
2. 新增“数据与存储”菜单。
3. 页面包含两个主要区域：
   - 清除图片缓存
   - 存储位置
4. 图片缓存清理不影响漫画/小说元信息、封面、自定义封面、标签、简介和下载文件。
5. 存储位置用于下载的漫画/小说，而不是图片缓存目录。

## 设置 key

文件：`lib/core/config/app_storage_keys.dart`

建议新增：

```dart
abstract final class AppStorageKeys {
  static const String legacyComicCacheDirectory = 'comic_cache_dir';

  static const String imageCacheMaxBytes = 'image_cache_max_bytes';
  static const String imageCacheCustomDirectory = 'image_cache_custom_dir';
  static const String downloadStorageDirectory = 'download_storage_dir';
}
```

说明：

- `comic_cache_dir` 是旧 key，不要直接复用为下载存储。
- 图片缓存目录通常用 App cache 目录即可，不一定暴露给用户选择。
- 用户明确要配置的是“存储位置”，即下载文件位置。

## 页面区域一：清除图片缓存

UI 文案：

```text
清除图片缓存
已使用：xxx MB
```

控件：

- 一个“最大缓存”滑块或下拉选择。
- 一个“清除”按钮。
- 一段小提示：建议不要频繁清理缓存。

建议默认：

```text
默认最大缓存：512 MB
可选范围：128 MB - 2048 MB
```

如果使用 Slider：

- min: 128
- max: 2048
- divisions: 15，步进 128 MB

清除按钮行为：

```dart
await imageCacheService.clearUnprotected();
await controller.reloadUsage();
```

只清理：

- 非封面
- 非自定义封面
- 非下载存储
- `cached_images.protected=0`

不清理：

- `comics/works` 主表
- `episodes/work_episodes`
- `library_tags`
- `library_work_tags`
- `library_work_state`
- `cover_local_path`
- `custom_cover_local_path`
- 下载存储目录

## 页面区域二：存储位置

UI 文案：

```text
存储位置
<当前路径>
```

按钮：

- 选择自定义目录
- 恢复默认

默认路径显示实际解析结果：

- Android：`/storage/emulated/0/Android/media/<包名>/Y300`
- iOS：App 文档目录下 `Y300`
- 其它平台：文档目录下 `Y300`

选择自定义目录：

1. 调用 `FilePicker.getDirectoryPath()`。
2. 保存到 `AppStorageKeys.downloadStorageDirectory`。
3. 创建：
   - `.nomedia`
   - `comics/.nomedia`
   - `novels/.nomedia`
   - `favorites.json` 如果不存在则初始化。

恢复默认：

1. 删除 shared preferences 中的自定义目录 key。
2. 重新解析默认目录。
3. 创建目录结构。

不要自动删除旧目录。

## Repository 职责

`DataStorageSettingsRepository`：

- 读取默认存储目录。
- 读取/保存自定义存储目录。
- 读取/保存图片缓存上限。
- 选择目录。

`ImageCacheService`：

- 计算图片缓存占用。
- 清除非保护缓存。
- prune 到上限。

`DownloadStorageService`：

- 初始化存储目录。
- 写 `.nomedia`。
- 初始化 `favorites.json`。

不要让 More 页面直接操作文件系统细节。

## 旧缓存目录设置迁移

当前旧 key：

```dart
AppStorageKeys.comicCacheDirectory = 'comic_cache_dir'
```

迁移建议：

1. 不把旧缓存目录自动当成下载存储目录。
2. 首次进入“数据与存储”时，如果发现旧 key 存在，可以提示：
   - “旧漫画缓存目录设置已停止使用，新的下载位置请在本页设置。”
3. 旧目录中的缓存图片由图片缓存服务按需识别或放弃。

如果要做平滑迁移：

- 只迁移仍存在且能被 `cached_images` 表关联的文件。
- 不做复杂目录扫描。

## UI 结构建议

不要使用大面积嵌套卡片。可以用 `ListView` + 分区标题 + `ListTile` + 控件。

示例结构：

```dart
ListView(
  padding: const EdgeInsets.all(16),
  children: [
    Text('清除图片缓存', style: theme.textTheme.titleLarge),
    const SizedBox(height: 4),
    Text('已使用：${formatBytes(state.imageCacheUsageBytes)}'),
    Slider(...),
    FilledButton.icon(...),
    const SizedBox(height: 24),
    Text('存储位置', style: theme.textTheme.titleLarge),
    const SizedBox(height: 4),
    Text(state.storagePath),
    FilledButton.icon(...),
    OutlinedButton.icon(...),
  ],
)
```

`formatBytes`：

- `< 1024 KB` 显示 KB
- `< 1024 MB` 显示 MB
- 否则显示 GB

## 与阶段 04/05 的关系

- 阶段 04 提供图片缓存统计、清理、上限。
- 阶段 05 提供下载存储路径和目录初始化。
- 阶段 06 只做 UI 和设置编排，不直接决定缓存/下载内部结构。
