# 阶段 4：实时刷新机制（事件总线）

**预计时间：5–7 小时**

## 1. 问题描述

当前各模块之间没有通信机制：

```
论坛收藏帖子 → 需要手动刷新收藏模块 → 需要手动刷新漫画/小说模块
自定义漫画标题 → 需要手动刷新漫画模块
```

期望行为：

```
论坛收藏帖子 → 收藏模块自动刷新 → 漫画/小说模块自动刷新
自定义漫画标题 → 漫画模块自动刷新
```

## 2. 设计目标

1. **解耦**：事件发射者和监听者彼此不直接依赖
2. **类型安全**：事件类型明确，携带结构化数据
3. **生命周期安全**：Widget dispose 后不再收到事件
4. **可测试**：可以 mock 事件总线进行单元测试

## 3. 架构设计

```
┌──────────────────────────────────────────────────────────┐
│                    AppEventBus (单例)                     │
│                                                          │
│  fire<T extends AppEvent>(event)                          │
│  on<T extends AppEvent>() → Stream<T>                    │
│  dispose()                                               │
│                                                          │
│  内部: StreamController<AppEvent>.broadcast()             │
└──────────┬────────────────────────────────┬──────────────┘
           │                                │
    ┌──────▼──────┐                  ┌──────▼──────┐
    │ 发射者       │                  │ 监听者       │
    │ - 论坛收藏   │                  │ - 收藏适配器  │
    │ - 收藏同步   │                  │ - 漫画适配器  │
    │ - 标题编辑   │                  │ - 小说适配器  │
    └─────────────┘                  │ - 搜索队列   │
                                     └─────────────┘
```

## 4. 核心实现

### 4.1 事件总线基础

**新文件：`lib/core/events/app_event_bus.dart`**

```dart
import 'dart:async';

/// 所有应用事件的基类
abstract class AppEvent {
  /// 事件发生时间
  final DateTime timestamp = DateTime.now();
}

/// 应用级事件总线
///
/// 使用 StreamController.broadcast() 实现多播，
/// 发射者与监听者之间零耦合。
///
/// 使用示例：
/// ```dart
/// // 发射
/// ref.read(appEventBusProvider).fire(FavoriteAdded(tid: '123'));
///
/// // 监听（在 Widget 中）
/// final stream = ref.read(appEventBusProvider).on<FavoriteAdded>();
/// ref.listenManual(stream, (_, event) {
///   // 处理事件
/// });
/// ```
class AppEventBus {
  final StreamController<AppEvent> _controller =
      StreamController<AppEvent>.broadcast();

  /// 发射事件
  void fire(AppEvent event) {
    if (!_controller.isClosed) {
      _controller.add(event);
    }
  }

  /// 监听特定类型的事件
  ///
  /// 返回一个过滤后的 [Stream]，只包含 [T] 类型的事件。
  Stream<T> on<T extends AppEvent>() {
    return _controller.stream.where((event) => event is T).cast<T>();
  }

  /// 关闭事件总线
  void dispose() {
    if (!_controller.isClosed) {
      _controller.close();
    }
  }
}
```

    _setupEventListeners();

### 4.6 自定义标题触发的刷新链

```
用户编辑漫画标题
  ↓
ComicRepository.updateCustomMetadata()
  ↓
AppEventBus.fire(ComicMetadataUpdated)
  ↓
两个消费者：
  ├─ UnifiedShelfController → 刷新漫画书架 UI
  └─ ComicDeepParseScheduler（可选） → 用新标题重新搜索章节
```

**修改文件：`lib/features/comic/domain/services/comic_deep_parse_scheduler.dart`**

```dart
class ComicDeepParseScheduler {
  void _setupEventListeners(AppEventBus eventBus) {
    _eventSub = eventBus.on<ComicMetadataUpdated>().listen((event) async {
      // 自定义标题变更后，用新标题重新搜索
      if (event.customSearchTitle != null || event.customTitle != null) {
        final newSearchTitle =
            event.customSearchTitle ?? event.customTitle ?? '';
        final comic = await _comicRepository.getComicDetail(
          comicId: event.comicId,
        );

        // 如果这个漫画在队列中，更新搜索标题
        // 如果不在队列中但是"長篇連載"，加入队列重试
        final hasCatalog = comic?.catalogUrl != null;
        final isLongSerial = (comic?.sourceTagName ?? '').contains('長篇連載');

        if (isLongSerial && !hasCatalog) {
          await _repository.enqueue(ComicDeepParseTask(
            comicId: event.comicId,
            title: newSearchTitle,
            sourceTid: comic!.sourceTid,
            sourceTagName: comic.sourceTagName ?? '',
            enqueuedAt: DateTime.now(),
            priority: DeepParsePriority.userRequested,
          ));
          start(); // 确保调度器在运行
        }
      }
    });
  }
}
```

## 5. 刷新流程时序

```
用户在论坛收藏帖子(tid=12345)
  │
  ▼
ForumFavoriteService.addFavorite(tid: '12345')
  │ API 调用成功
  ▼
AppEventBus.fire(ForumFavoriteAdded(tid: '12345'))
  │
  ├─→ UnifiedShelfController._handleEvent()
  │     │ 识别 ForumFavoriteAdded
  │     ▼
  │   FavoriteShelfAdapter.refreshShelf()
  │     │ FavoriteSyncService.sync() 触发
  │     ├─ 拉取 myfavthread 列表
  │     ├─ 增量更新（因为非首次，走 incremental 模式）
  │     ├─ 只有新增的帖子(tid=12345)被处理
  │     ├─ 分类为 comic/novel/forum
  │     ├─ 摄入对应模块
  │     ▼
  │   AppEventBus.fire(FavoriteSyncCompleted(...))
  │     │
  │     ├─→ 收藏模块 UI 刷新 ✓
  │     ├─→ 漫画模块 UI 刷新 ✓（如果新增的是漫画）
  │     └─→ 小说模块 UI 刷新 ✓（如果新增的是小说）
  │
  └─→ 其他监听者（如果有）
```

```dart

  const AppResumed();
}

```dart
eventBus.on<AppResumed>().listen((_) async {
  await _syncIfNeeded();

## 8. 验收标准

1. ✅ 论坛收藏帖子后，收藏模块自动刷新
2. ✅ 收藏刷新后，漫画/小说模块自动刷新
3. ✅ 自定义漫画标题后，漫画模块自动刷新
4. ✅ 事件总线零耦合：删除任一监听者不影响发射者
5. ✅ Widget dispose 后不再收到事件（通过 StreamSubscription.cancel）
6. ✅ 可以注入 mock EventBus 进行单元测试
7. ✅ 事件日志可追踪（开发模式下打印事件类型和时间戳）
