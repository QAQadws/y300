# 阶段 3.5：在帖子详情页添加收藏按钮（替代加入书架）

**预计时间：3–4 小时**

## 1. 目标

用**统一的收藏按钮**替代现有的分散操作，简化帖子详情页的交互：

- **移除**：`CandidateShelfActionRow`（"加入漫画书架"/"加入小说书架"按钮）
- **新增**：AppBar 收藏按钮（一个按钮统一处理所有帖子类型）
- **效果**：收藏后自动触发全链路刷新——收藏模块 + 根据 `fid` 刷新对应的漫画/小说模块

### 1.1 为什么要移除"加入书架"按钮

当前页面有两套入口：
1. `CandidateShelfActionRow` — 直接操作本地书架（不过收藏 API）
2. （计划新增的）收藏按钮 — 操作论坛收藏夹 API

这让用户困惑。正确的设计是：
- **论坛收藏 API 是唯一的数据入口**
- 收藏后，阶段 1 的解析管道自动分类并摄入漫画/小说模块
- 用户不需要知道"书架"和"收藏夹"的区别——收藏了漫画帖子，它就自动出现在漫画模块


```dart
/// 切换收藏状态，并触发后续刷新链
Future<void> toggleFavorite() async {
  final current = state.value;
  if (current == null || current.isFavoriteActionLoading) return;
  final snapshot = current;

  state = AsyncData(snapshot.copyWith(
    isFavoriteActionLoading: true,
    clearError: true,
  ));

  try {
    final service = ref.read(forumFavoriteServiceProvider);

    if (snapshot.isFavorited) {
      // 取消收藏
      final favid = await _findFavid(snapshot.tid);
      if (favid == null) {
        throw StateError('未找到收藏记录，无法取消收藏');
      }
      final result = await service.removeFavorite(favid: favid);
      if (result case ApiSuccess(:final data)) {
        if (data.success) {
          _updateFavoriteState(snapshot, isFavorited: false);
          ref.read(appEventBusProvider).fire(
            ForumFavoriteRemoved(favid: favid, tid: snapshot.tid),
          );
          // 取消收藏后也需要刷一轮（该帖子会从收藏模块和对应模块消失）
          _triggerRefreshChain(snapshot.fid);
        } else {
          _showFavoriteError(snapshot, data.message);
        }
      } else {
        _showFavoriteError(snapshot, (result as ApiFailure).error.message);
      }
    } else {
      // 添加收藏
      final result = await service.addFavorite(tid: snapshot.tid);
      if (result case ApiSuccess(:final data)) {
        if (data.success) {
          _updateFavoriteState(snapshot, isFavorited: true);
          ref.read(appEventBusProvider).fire(
            ForumFavoriteAdded(tid: snapshot.tid),
          );
          // 收藏成功后触发全链路刷新
          _triggerRefreshChain(snapshot.fid);
        } else {
          _showFavoriteError(snapshot, data.message);
        }
      } else {
        _showFavoriteError(snapshot, (result as ApiFailure).error.message);
      }
    }
  } catch (error) {
    if (!mounted) return;
    state = AsyncData(snapshot.copyWith(
      isFavoriteActionLoading: false,
      errorMessage: '收藏操作失败：$error',
    ));
  }
}

/// 触发收藏同步 + 按 fid 刷新对应模块
///
/// 流程：
/// 1. FavoriteSyncService 增量同步 → 解析管道 → 摄入模块
/// 2. 收藏模块 UI 自动刷新
/// 3. 按 fid 确定目标模块并刷新
void _triggerRefreshChain(String fid) {
  final bus = ref.read(appEventBusProvider);

  // 收藏模块刷新由 UnifiedShelfController 在收到 ForumFavoriteAdded 后自动处理。
  // 这里额外发出模块级刷新信号，确保漫画/小说书架也即时更新。

  switch (fid) {
    case '30':
      // 漫画版块 → 漫画模块需要刷新
      bus.fire(const ComicsModuleShouldRefresh());
      break;
    case '49':
    case '55':
      // 小说版块 → 小说模块需要刷新
      bus.fire(const NovelsModuleShouldRefresh());
      break;
    default:
      // 其他版块 → 仅收藏模块需要刷新（已由 FavoriteListShouldRefresh 覆盖）
      break;
  }
}

void _updateFavoriteState(ThreadDetailPageState snapshot, {required bool isFavorited}) {
  if (!mounted) return;
  state = AsyncData(snapshot.copyWith(
    isFavorited: isFavorited,
    isFavoriteActionLoading: false,
  ));
}

void _showFavoriteError(ThreadDetailPageState snapshot, String message) {
  if (!mounted) return;
  state = AsyncData(snapshot.copyWith(
    isFavoriteActionLoading: false,
    errorMessage: message,
  ));
}

/// 从本地收藏缓存中查找 favid
Future<String?> _findFavid(String tid) async {
  final localRepo = ref.read(localFavoriteRepositoryProvider);
  final record = await localRepo.getActiveThreadByTid(tid);
  return record?.favid;
}
```

```dart
Future<ThreadDetailPageState> _loadPage({
  required int page,
  required List<ThreadPost> previous,
}) async {
  final result = await _readRepository().getThreadDetail(tid: _args.tid, page: page);

  if (result case ApiSuccess<ThreadDetailData>(:final data)) {
    final merged = page == 1 ? data.posts : <ThreadPost>[...previous, ...data.posts];
    final subject = data.subject.isNotEmpty ? data.subject : _args.subject;
    final sourceTagName = await _findSourceTagName(
      fid: data.fid,
      typeid: data.typeid,
    );
    final contentKind = ref.read(threadContentClassifierProvider).classify(
          fid: data.fid,
          typeid: data.typeid,
          tagName: sourceTagName,
        );

    // 移除了 isInShelf / isNovelInShelf / comicCandidate 检测
    // 改为仅检查是否已收藏
    var isFavorited = false;
    try {
      final localRepo = ref.read(localFavoriteRepositoryProvider);
      final existing = await localRepo.getActiveThreadByTid(_args.tid);
      isFavorited = existing != null;
    } catch (_) {}

    return ThreadDetailPageState(
      tid: _args.tid,
      fid: data.fid,
      typeid: data.typeid,
      sourceTagName: sourceTagName,
      contentKind: contentKind,
      subject: subject,
      currentPage: data.currentPage,
      hasMore: data.hasMore,
      isLoadingInitial: false,
      isLoadingMore: false,
      posts: merged,
      isFavorited: isFavorited,
      isFavoriteActionLoading: false,
      replyText: '',
      isReplySubmitting: false,
      replyHint: null,
    );
  }

  final error = (result as ApiFailure<ThreadDetailData>).error;
  return ThreadDetailPageState(
    tid: _args.tid,
    fid: '',
    typeid: '',
    sourceTagName: null,
    contentKind: ThreadContentKind.forum,
    subject: _args.subject,
    currentPage: page == 1 ? 0 : page,
    hasMore: false,
    isLoadingInitial: false,
    isLoadingMore: false,
    posts: previous,
    isFavorited: false,
    isFavoriteActionLoading: false,
    replyText: '',
    isReplySubmitting: false,
    replyHint: null,
    errorMessage: error.message,
  );
}
```

```dart
class _FavoriteButton extends StatelessWidget {
  const _FavoriteButton({
    required this.fid,
    required this.isFavorited,
    required this.isLoading,
    required this.onToggle,
  });

  final String fid;
  final bool isFavorited;
  final bool isLoading;
  final VoidCallback onToggle;

  String get _tooltip {
    if (isFavorited) return '取消收藏';
    switch (fid) {
      case '30':
        return '收藏漫画';
      case '49':
      case '55':
        return '收藏小说';
      default:
        return '收藏帖子';
    }
  }

  @override
  Widget build(BuildContext context) {
    if (isLoading) {
      return const Padding(
        padding: EdgeInsets.all(12),
        child: SizedBox(
          width: 20,
          height: 20,
          child: CircularProgressIndicator(strokeWidth: 2),
        ),
      );
    }

    return IconButton(
      key: const Key('thread-detail-favorite-button'),
      tooltip: _tooltip,
      onPressed: onToggle,
      icon: Icon(
        isFavorited ? Icons.bookmark : Icons.bookmark_border,
        color: isFavorited
            ? Theme.of(context).colorScheme.primary
            : null,
      ),
    );
  }
```

### 5.2 取消收藏的连锁反应

取消收藏后，因 `FavoriteSyncService` 增量同步发现该 tid 不在远程列表中，
会将其标记为 `removed`，并调用 `_removeModuleShelfItems()` 从漫画/小说书架移除。

整个流程由事件驱动，不需要在 `toggleFavorite` 中手动处理。

### 5.3 取消收藏的 favid 缺失

如果 favid 不在本地缓存（首次使用、未同步过），取消收藏按钮行为：

- **推荐方案**：`isFavorited == true && favid == null` 时，按钮显示实心书签但不可点击（或点击只弹 toast "取消收藏请到收藏页操作"）

```dart
// 在状态中增加一个标记

isFavorited = existing != null;
canUnfavorite = existing?.favid != null;
```

- `addToShelf` 和 `addNovelToShelf` 相关测试需要删除
- `comicCandidateInfo` / `parsedComicPost` 相关断言需要移除
- 新增 `toggleFavorite` 的单元测试
