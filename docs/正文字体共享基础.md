# 正文字体共享基础

## 职责与公开入口

共享字体能力位于 `lib/features/fonts/`，消费者通过 `fonts.dart` 使用服务、字体值与 `showBodyFontSelector`。它负责本机字体文件、运行时注册和选择器草稿；小说、论坛及日志各自的偏好保存、正文应用、布局失效和位置恢复由调用方负责装配。

`FontLibraryService` 提供列表、导入、删除和 `resolveFont`；`ResolvedFont` 是可传递的已解析纯值，包含稳定 ID 和可空的引擎字体名称，`cacheKey` 使用内容身份。`FontResolution` 同时携带请求 ID 与可选失败类型，界面通过本地化映射呈现错误，业务层不返回 UI 文案。

## 字体身份与持久化

- 系统字体使用固定 ID `system`，解析值的 `fontFamily` 为 `null`。
- 导入字体 ID 为文件完整内容的 SHA-256，小写 64 位十六进制；运行时名称为 `Y300ImportedFont_<id>`。用户文件名只用于显示，同名不同内容互不覆盖，同内容更名后导入复用已有条目。
- 文件位于应用支持目录的 `fonts/`，按检测到的容器保存为 `<id>.ttf` 或 `<id>.otf`。索引只保存派生相对文件名，不保存选择器外部路径；文件复制成功后不再依赖原文件。
- `index.json` 格式版本为 1，条目包含 `id`、`displayName`、`storageFileName` 和 `byteLength`。字体上限 64 MiB，索引上限 1 MiB、4096 项；读入时验证类型、身份、范围和规范相对路径。
- 列表读取只加载元数据；缺失或损坏文件仍保留条目，允许用户删除或重新导入修复。实际读取字体时核对长度、内容摘要和 SFNT 结构，不使用失效文件。
- 字体目录是持久数据，不进入图片或页面缓存。字体文件与测试字体均不声明为 APK 的 Flutter assets；统一容量统计由应用存储装配后续接入。

## 提交与故障恢复

仓库内操作串行执行。字体和索引先写入临时文件并 flush，索引替换期间保留此前已提交的 `.bak`。启动读取只恢复缺失正式索引时的有效备份，不采纳未提交的 `.tmp` 或孤立字体；正式索引损坏或来自未来版本时返回类型化失败，不用空列表覆盖原数据。

导入经过结构校验和运行时加载后才发布仓库条目，失败保留已有数据。同内容再次导入可以修复对应私有文件，同时保留原显示名。校验和摘要计算在独立 isolate 执行；选择器按流读取外部文件，同时限制声明大小与实际字节数，并复制来源缓冲区。

删除以索引成功移除为提交点，再尽力移除对应私有文件。物理删除失败可能留下无索引的文件，不重新采纳该文件；索引写入失败则保留原条目和文件。仅持久提交成功发送字体库变更事件；仓库销毁会先停止接收操作，再等待已接收操作完成并关闭事件流。

## 运行时加载与失败回退

TTF/OTF 校验覆盖 SFNT 目录、核心表及有界数据范围，拒绝伪装成字体的 TTC、WOFF 等容器。它不是完整的字形解释器：部分无效字形可能被平台静默回退，不能把 Flutter 加载 Future 完成等同于字形一定成功显示，也不保证字体包含全部 Unicode 字符。

运行时按内容身份合并在途加载并复用成功注册；失败注册可重试。引擎注册是追加式的，删除字体撤销持久引用和后续选择，不承诺立即释放引擎中已经注册的字体内存。

`resolveFont` 对缺失、损坏、库读取异常或加载失败返回系统字体与具体失败类型。解析服务不擅自重写调用方偏好，调用方依据返回值决定提示与失效引用修复。删除请求立即隔离该 ID 的在途解析及排队期间新解析；服务销毁后的迟到加载不会发布可用选择。

## 共用选择器

`showBodyFontSelector` 接收初始字体 ID 和可选样文样式，返回确认后的 `ResolvedFont`，取消返回 `null`。初始状态、切换与确认均等待字体解析，确认前重新核对文件有效性；异步列表、选择、导入和删除按独立请求代次处理。

字体库的导入和删除即时生效；取消只放弃场景字体选择，不撤销已经完成的文件管理。选择器不保存小说或论坛的阅读偏好。删除当前草稿字体时回到系统默认，其他消费者通过变更流与重新解析处理失效引用。

样文沿用调用场景的排版和主题，系统预览显式清除自定义 family，避免 `TextStyle.copyWith(fontFamily: null)` 保留旧字体。所有新增可见文字、tooltip、加载语义和样文来自简繁 ARB。
