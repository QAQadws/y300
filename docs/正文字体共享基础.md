# 正文字体共享基础

## 职责与公开入口

共享字体能力位于 `lib/features/fonts/`，消费者通过 `fonts.dart` 使用服务、字体值与 `showBodyFontSelector`。它负责本机字体文件、运行时注册和选择器草稿；场景偏好保存、正文应用、布局失效和位置恢复由调用方负责装配。小说独立选择字体，论坛与日志共用选择。

`FontLibraryService` 提供列表、导入、删除和 `resolveFont`；`ResolvedFont` 是可传递的已解析纯值，包含稳定 ID 和可空的引擎字体名称，`cacheKey` 使用内容身份。`FontResolution` 同时携带请求 ID 与可选失败类型，界面通过本地化映射呈现错误，业务层不返回 UI 文案。

## 字体身份与持久化

- 系统字体使用固定 ID `system`，解析值的 `fontFamily` 为 `null`。
- 导入字体 ID 为文件完整内容的 SHA-256，小写 64 位十六进制；运行时名称为 `Y300ImportedFont_<id>`。用户文件名只用于显示，同名不同内容互不覆盖，同内容更名后导入复用已有条目。
- 文件位于应用支持目录的 `fonts/`，按检测到的容器保存为 `<id>.ttf` 或 `<id>.otf`。索引只保存派生相对文件名，不保存选择器外部路径；文件复制成功后不再依赖原文件。
- `index.json` 格式版本为 1，条目包含 `id`、`displayName`、`storageFileName` 和 `byteLength`。字体上限 64 MiB，索引上限 1 MiB、4096 项；读入时验证类型、身份、范围和规范相对路径。
- 列表读取只加载元数据；缺失或损坏文件仍保留条目，允许用户删除或重新导入修复。实际读取字体时核对长度、内容摘要和 SFNT 结构，不使用失效文件。
- 字体目录是持久数据，不进入图片或页面缓存。字体文件与测试字体均不声明为 APK 的 Flutter assets；实际占用通过应用统一存储统计装配。

## 存储统计与清理边界

`FontLibraryStorageUsage.calculateUsageBytes` 是只读容量端口，与文件读写接口由同一个私有仓库实例提供。统计进入仓库串行队列，等待此前已接受的导入、删除完成；计算目录内实际普通文件字节数，包含字体、索引、临时／备份文件及无索引遗留，不把索引声明长度当作实际占用。

统计不创建字体目录、不解析或恢复索引、不发字体库变更事件，也不跟随文件或目录符号链接。目录缺失返回零，其他 I/O 失败保留类型化错误，不把读取失败报告为零。统计只反映磁盘文件，不包括引擎已注册字体的内存。

`FontLibraryStorageAccountingAdapter` 归字体 owner，`app/storage` 负责将其注册一次到统一报表。稳定分类 ID 为 `font_library`，整类 `clearable=false`，分项标记 `protected=true`；More presentation 通过简繁 ARB 映射“导入字体”／“匯入字型”。占用进入既有 Debug 存储总览与诊断导出，不计入可清缓存容量和缓存预算。

默认、图片、页面及用户缓存清理和缓存容量裁剪均保留字体文件与索引；用户通过共用字体选择器删除条目。下载根目录选择与迁移不接管应用支持目录中的字体，不改变稳定字体 ID 或私有文件位置。

## 提交与故障恢复

仓库内操作串行执行。字体和索引先写入临时文件并 flush，索引替换期间保留此前已提交的 `.bak`。启动读取只恢复缺失正式索引时的有效备份，不采纳未提交的 `.tmp` 或孤立字体；正式索引损坏或来自未来版本时返回类型化失败，不用空列表覆盖原数据。

导入经过结构校验和运行时加载后才发布仓库条目，失败保留已有数据。同内容再次导入可以修复对应私有文件，同时保留原显示名。校验和摘要计算在独立 isolate 执行；选择器按流读取外部文件，同时限制声明大小与实际字节数，并复制来源缓冲区。

删除以索引成功移除为提交点，再尽力移除对应私有文件。物理删除失败可能留下无索引的文件，不重新采纳该文件；索引写入失败则保留原条目和文件。仅持久提交成功发送字体库变更事件；仓库销毁会先停止接收操作，再等待已接收操作完成并关闭事件流。

## 运行时加载与失败回退

TTF/OTF 校验覆盖 SFNT 目录、核心表及有界数据范围，拒绝伪装成字体的 TTC、WOFF 等容器。它不是完整的字形解释器：部分无效字形可能被平台静默回退，不能把 Flutter 加载 Future 完成等同于字形一定成功显示，也不保证字体包含全部 Unicode 字符。

运行时按内容身份合并在途加载并复用成功注册；失败注册可重试。引擎注册是追加式的，删除字体撤销持久引用和后续选择，不承诺立即释放引擎中已经注册的字体内存。

`resolveFont` 对缺失、损坏、库读取异常或加载失败返回系统字体与具体失败类型。解析服务不擅自重写调用方偏好，调用方依据返回值决定提示与失效引用修复。删除请求立即隔离该 ID 的在途解析及排队期间新解析；服务销毁后的迟到加载不会发布可用选择。

## 共用选择器

`showBodyFontSelector` 接收初始字体 ID 和可选样文样式，返回确认后的 `ResolvedFont`，取消返回 `null`。初始状态、切换与确认均等待字体解析，确认前重新核对文件有效性；异步列表、选择、导入和删除按独立请求代次处理。

字体库的导入和删除即时生效；取消只放弃场景字体选择，不撤销已经完成的文件管理。选择器不保存小说或论坛的阅读偏好。删除当前草稿字体时回到系统默认，其他消费者通过变更流与重新解析处理失效引用。

样文沿用调用场景的排版和主题，系统预览显式清除自定义 family，避免 `TextStyle.copyWith(fontFamily: null)` 保留旧字体。所有新增可见文字、tooltip、加载语义和样文来自简繁 ARB。

## 小说阅读器接入

小说的“显示设置 → 字体”使用共用选择器；仅确认后的稳定 ID 进入现有显示设置协调器。样文继承当前阅读主题与已解析字体，并使用显示设置草稿中的最新字号、行距。取消选择不改变阅读偏好。

现有 schema-1 小说偏好快照增加可选 `fontFamily` 字段，保存 `system` 或小写 SHA-256 ID；旧快照缺少该字段时使用系统默认。原始路径、引擎注册名称和其他无效值均不作为持久字体身份，其余偏好与既有阅读模式兼容规则保持不变。

`NovelReaderViewState.fontResolution` 保存本次运行时解析结果，`bodyFont` 提供实际字体值。冷启动和章节切换在首次正文发布前等待解析；字体预览保留已读正文，待请求字体就绪后同时发布偏好与字体值。加载、目录变化、较早保存和新章节通过各自请求代次隔离，较早结果不得覆盖最新选择。系统回退后保留的暂时失败引用可以在字体库变化后重新解析。

字体删除或失效时保持正文可读。可确认的缺失或损坏引用通过既有显示设置协调器的独立串行维护任务修复为系统默认，等待此前已接受的保存后，只修补执行时已确认偏好的字体字段；不重新开始或确认当前草稿，不重置预览节流与保存防抖。修复仍核对当前 owner、session、提交代次与引用，写入失败只尝试一次，不回滚无关草稿或产生自动重排／保存循环。

暂时的存储、加载失败保留请求字体 ID。`editablePreferences` 为设置页提供带原 ID 的编辑快照，实际正文继续使用已解析的系统回退；保存字号、主题等其他设置时仍持久保存原 ID，明确选择系统字体时才替换。字体库恢复后可以重新解析原选择，不因一次临时失败永久丢失偏好。

排版 resolver 只消费 `ResolvedFont.fontFamily`，不把持久 ID 传给 Flutter。横向可见 HTML、TextPainter 和测量 Overlay 共用已捕获的实际排版环境；纵向 HTML 显式接收相同基准 TextStyle 和对齐，保留作者 CSS 与粗斜体。字体身份参与阅读 surface 与布局缓存身份；prepared HTML 仍保持字体中立并复用，纵向内容按独立布局身份发出新 ready 信号，旧布局的迟到回调不能确认新几何。

同一阅读会话的横向字体重排优先使用当前可见语义锚点。仅在原始 HTML、转换来源、章节、prepared HTML／内容身份、规范化版本和两侧实际语义 coverage 一致时保留原锚点；随后由新分页计划核对实际页覆盖。该提示按布局身份安装一次，保持只读，真实阅读导航才退役提示并确认新位置。正文、转换或身份不匹配时沿用原有恢复策略，不猜节点对应；旧、未来或近似位置不因换字体、补页或退出而迁移。

原帖阅读接管、重置或其他权威位置更新会退役此前的可见提示；阅读权威与 surface 代次同时参与失效，旧页或迟到投影不能覆盖返回的新公共位置。该规则与字体重排复用同一导航身份检查。

纵向重排沿用既有 `bodyGeometryV1` 正文比例恢复与就绪门控，不把原字体下的绝对像素偏移当作新字体的语义位置。惰性布局下的几何估计仍遵循现有有界恢复策略，不宣称能逐字符精确恢复纵向首行。

## 论坛与日志接入

论坛帖子、日志正文及评论、各自的选择复制页共用 `ForumHtmlReaderPreferences.fontFamily`，默认 `system`。类型化键 `reader.forum_html.font_family.v1` 只保存稳定内容 ID；缺少键的旧安装继续使用系统字体，不改变既有字号、行距、作者样式或转换偏好迁移。小说的选择仍独立保存。

`forumHtmlReaderFontBindingProvider` 提供同一时刻的偏好快照、已解析字体、字体缓存身份和就绪状态。偏好与字体在冷启动时一并就绪后才显示正文；更换字体时保留先前可读的偏好和样式，加载完成后同时发布。较早选择、保存、目录事件或销毁后的结果不能覆盖新状态。系统回退从当前场景 Theme 的基准正文样式重新构造，避免继承此前的自定义 family。

帖子现有正文设置与日志详情的正文设置按钮复用同一个 `ForumHtmlReaderSettingsSheet` 和字体选择器，确认后通过共享控制器保存。文章与对应选择复制页监听同一个绑定，因此已打开的页面会同步更新。日志仍使用自己的显示文本投影，设置入口不启用论坛转换控件，也不重做原始日志内容转换。

独立帖子正文及分块正文均显式传入已解析的基准 TextStyle，作者 CSS 和粗斜体继续覆盖默认样式。字体参与布局及分块高度身份，默认 HTML 准备结果保持字体中立并复用；同一 HTML 的样式或图片 Host 换绑保留折叠状态和正文 Element。旧布局与旧阅读观察回调按绑定身份退役。

通用 `ForumHtmlContentView` 通过默认关闭的 `useSharedReaderFont` 显式选择阅读字体。日志文章、评论和选择复制页开启；编辑器预览、富文本 embed 和其他未接入消费者保持原有字体行为。渲染包只接收纯排版值，不访问字体库、偏好或 provider。

删除或损坏在用字体会立即回退可读的系统样式，并通过共享偏好 writer 修复持久引用。修复等待此前已接受的写入，重新读取最后确认的偏好，仅将仍指向失效 ID 的字体字段改为 `system`；不会提交未确认的排版草稿、覆盖正在保存的其他字段，或清除后来选择的有效字体。修复失败保留可读回退且只尝试一次；字体库变化也会重新核对暂时失败的原引用。暂时回退期间保存字号、行距或转换设置仍保留原字体 ID，仅显式选择字体或重置才替换该引用。删除与其他页面同时更新字号时，以最新偏好再次核对，不取消新的字体选择意图。
