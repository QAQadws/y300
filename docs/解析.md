下面分开介绍 `sendpm` 和 `checknewpm`，包括用途、请求方式、参数与预期结果，并给出可直接调用的示例。

**1) `sendpm`（发送私信）**  
它把请求路由到 `home.php?mod=spacecp&ac=pm&op=send`，并把 `$_GET` 复制到 `$_POST` 以便统一读取参数。sendpm.php

**请求方式**
- 必须登录（需要 Cookie）。
- 提交依赖 `submitcheck('pmsubmit')`，因此建议 **POST + formhash**。spacecp_pm.php helper_form.php
- 参数既可放 URL，也可放 body（因为 `$_POST = $_GET`）。sendpm.php

**常用参数**
- `pmsubmit=1`：触发发送。spacecp_pm.php
- `message`：私信正文（必填，空会报错）。spacecp_pm.php
- 目标用户三选一：
  - `touid`（或 `uid`）：给单个用户发。spacecp_pm.php spacecp_pm.php
  - `users[]` 或 `username`：给多个用户发。spacecp_pm.php
  - `pmid` + `topmuid`：对已有私信回复。spacecp_pm.php
- 可选：
  - `type=1` 时可带 `subject`。spacecp_pm.php
  - `messageappend`：自动拼接在正文前。spacecp_pm.php

**示例（发给单人）**
```http
POST https://bbs.yamibo.com/api/mobile/index.php?module=sendpm&version=4
Content-Type: application/x-www-form-urlencoded
Cookie: <登录态>

formhash=xxxxx&pmsubmit=1&touid=12345&message=你好
```

**示例（发给多人）**
```http
POST https://bbs.yamibo.com/api/mobile/index.php?module=sendpm&version=4
Content-Type: application/x-www-form-urlencoded
Cookie: <登录态>

formhash=xxxxx&pmsubmit=1&users[]=Alice&users[]=Bob&message=大家好
```

**预计结果**
- 成功：响应里会带 `Variables.pmid`（私信 ID）。sendpm.php
- 失败：通常返回 `Message.messageval/messagestr`（权限、黑名单、空内容、频率限制等）。spacecp_pm.php mobile.class.php

未使用图片管理 — HTTP 接口规范
一、获取未使用图片列表
请求


GET https://bbs.yamibo.com/forum.php?mod=ajax&action=imagelist&posttime=0
请求头：携带已登录会话的 Cookie（auth、saltkey 等 Discuz 登录 cookie）

参数

参数	必填	说明
mod	是	固定 ajax
action	是	固定 imagelist
posttime	否	固定传 0。它是"只返回该时间之后上传的图片"的过滤，传 0 = 不过滤 = 返回全部；传当前时间会一条都查不到
fid	否	版块 ID，过滤允许的扩展名；不传则不过滤
pid	否	编辑帖子时用；管理未使用图片时可省略
响应：<root><![CDATA[ HTML片段 ]]></root> 包裹的 HTML，不是 JSON。每个图片条目是一个 <td>，结构（可解析字段）：


<td id="image_td_{aid}">
  <img src="forum.php?mod=image&aid={aid}&size=300x300&key={key}&nocache=yes" />
  <a onclick="delImgAttach({aid},1)">删除</a>
  <input name="attachnew[{aid}][description]" />       <!-- 描述 -->
  <input id="albumaid_{aid}" value="" />                <!-- 相册 -->
</td>
解析要点

aid（图片 ID）：正则 id="image_td_(\d+)"
图片显示 URL：正则 src="([^"]+)"，相对路径，前面拼接站点域名：https://bbs.yamibo.com/ + src
描述：name="attachnew[{aid}][description]" 对应 input 的 value
只能拿到当前登录用户自己的：服务端按会话 uid 过滤（af.uid=当前用户 AND a.tid=0）
二、删除未使用图片
请求


GET https://bbs.yamibo.com/forum.php?mod=ajax&action=deleteattach&inajax=yes&formhash={formhash}&tid=0&pid=0&aids[]={aid1}&aids[]={aid2}
请求头：携带已登录会话 Cookie

参数

参数	必填	说明
mod	是	固定 ajax
action	是	固定 deleteattach
formhash	是	登录会话的防伪造令牌，缺失则删除直接失败
tid	是	固定 0（未使用图片 = 未被帖子使用）
pid	是	固定 0（同上）
aids[]	是	要删的图片 ID，可重复多个批量删
响应：<root><![CDATA[ {数字} ]]></root>，数字 = 成功删除的数量

内部行为（Discuz 源码确认）：

校验 formhash 与会话匹配，不符直接失败
逐条权限校验：!pid && uid == 当前用户（未使用且是你上传的）或版主 → 否则跳过该条
删除 pre_forum_attachment_unused 记录（按 tableid=127 路由）
删除 pre_forum_attachment 总表记录
dunlink() 删除物理文件（原图 + 缩略图）
错误情况

返回数字 小于请求的 aids 数量：部分或全部失败（无权限 / aid 不存在）
formhash 缺失或过期：不返回数字，返回错误提示
