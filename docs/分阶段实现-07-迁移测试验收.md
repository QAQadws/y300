# 分阶段实现 07：迁移、测试与验收

本阶段用于把前面几个阶段收束成可安全发布的实现。重点是 SQLite 迁移、旧数据兼容、自动化测试和手工验收。

## SQLite 迁移建议

当前 `ComicLocalDb.dbVersion = 9`。

后续不要在同一个版本里塞太多不相关迁移。推荐按功能分版本：

### v10：标签与 typeid

```sql
ALTER TABLE comics ADD COLUMN source_typeid TEXT;
ALTER TABLE comics ADD COLUMN source_tag_name TEXT;
ALTER TABLE works ADD COLUMN source_typeid TEXT;
ALTER TABLE works ADD COLUMN source_tag_name TEXT;
```

如果已经实现本地封面字段，也可以在 v10 或 v11：

```sql
ALTER TABLE comics ADD COLUMN cover_local_path TEXT;
ALTER TABLE comics ADD COLUMN custom_cover_local_path TEXT;
ALTER TABLE works ADD COLUMN cover_local_path TEXT;
ALTER TABLE works ADD COLUMN custom_cover_local_path TEXT;
```

### v11：收藏同步

```sql
CREATE TABLE IF NOT EXISTS favorite_sync_state (...);
CREATE TABLE IF NOT EXISTS favorite_threads (...);
CREATE TABLE IF NOT EXISTS favorite_categories (...);
CREATE TABLE IF NOT EXISTS favorite_thread_category (...);
CREATE INDEX IF NOT EXISTS idx_favorite_threads_kind_order ...;
```

### v12：图片缓存实体化

```sql
CREATE TABLE IF NOT EXISTS cached_images (...);
ALTER TABLE episode_images ADD COLUMN stable_cache_key TEXT;
ALTER TABLE episode_images ADD COLUMN last_source_url TEXT;
ALTER TABLE episode_images ADD COLUMN local_path TEXT;
ALTER TABLE episode_images ADD COLUMN bytes INTEGER;
ALTER TABLE episode_images ADD COLUMN mime_type TEXT;
ALTER TABLE episode_images ADD COLUMN last_accessed_at INTEGER;
ALTER TABLE episode_images ADD COLUMN protected INTEGER NOT NULL DEFAULT 0;
```

注意 SQLite `ALTER TABLE ADD COLUMN ... NOT NULL DEFAULT` 是可以的，但不要给非空列加没有 default 的约束。

### v13：下载存储状态

下载存储主要在文件系统中，但 DB 可以增加索引状态：

```sql
CREATE TABLE IF NOT EXISTS downloaded_assets (
  id TEXT PRIMARY KEY,
  content_type TEXT NOT NULL,
  work_id TEXT NOT NULL,
  episode_id TEXT,
  storage_path TEXT NOT NULL,
  kind TEXT NOT NULL,
  bytes INTEGER NOT NULL DEFAULT 0,
  created_at INTEGER NOT NULL,
  updated_at INTEGER NOT NULL
)
```

这张表不是必须的，但有助于快速判断某章节是否已下载，而不必频繁扫文件系统。

## 旧数据兼容策略

### 1. 旧漫画封面 URL

旧数据只有 `cover_image_url`。

兼容：

- `cover_local_path` 为空时，仍允许短期用 `cover_image_url` 显示。
- 第一次进入详情页或书架刷新时，尝试缓存封面实体。
- 成功后写入 `cover_local_path`。

### 2. 旧 episode_images

旧数据只有 `image_url/cache_local_path/cache_status`。

兼容：

- `stable_cache_key` 为空时按 `comicId/episodeId/imageIndex` 生成并回填。
- `last_source_url` 为空时使用 `image_url`。
- `local_path` 为空但 `cache_local_path` 存在时，检查文件存在并迁移。

### 3. 旧小说 works

旧数据没有 `typeid/tagName`。

兼容：

- 收藏同步后通过 tid 进帖补全。
- 如果不是收藏同步产生的旧小说，详情页可以显示无自带标签。

### 4. 旧缓存目录设置

旧 key `comic_cache_dir` 不再作为下载存储路径。

兼容：

- 保留读取能力用于旧图片缓存迁移。
- UI 不再显示“缓存目录”。
- 新设置使用 `download_storage_dir` 和 `image_cache_max_bytes`。

## 手工验收路径

### 1. 标签和详情页

1. 打开漫画版块 `fid=30` 的非公告帖子。
2. 确认帖子详情显示漫画入口。
3. 打开漫画详情页。
4. 确认简介下方第一枚标签为论坛自带标签。
5. 添加一个自定义标签。
6. 确认自带标签在最前，自定义标签在后。

### 2. 公告排除

1. 打开 `fid=30,typeid=65` 公告帖子。
2. 确认不进入漫画模块。
3. 打开 `fid=49,typeid=121` 公告帖子。
4. 确认不进入小说模块。
5. 打开 `fid=55,typeid=147` 公告帖子。
6. 确认不进入小说模块。

### 3. 收藏首次同步

1. 登录账号。
2. 进入“收藏”Tab。
3. 首次同步拉取所有收藏。
4. 同步完成后确认“漫画”“小说”“默认”分类数量之和等于远程 count。
5. 点击漫画收藏，进入漫画详情页。
6. 点击小说收藏，进入小说详情页。
7. 点击普通收藏，进入帖子详情页。

### 4. 收藏增量

1. 在网页或 App 外新增一个收藏。
2. 回到 App 下拉刷新收藏页。
3. 确认只新增对应帖子并补全信息。
4. 取消收藏一个漫画。
5. 刷新收藏页。
6. 确认收藏页和漫画模块都不再显示该作品。

### 5. 图片 URL 变化

1. 打开漫画第一话，让图片缓存。
2. 模拟同一章节图片 URL 变化。
3. 再次打开章节。
4. 确认优先使用本地缓存，不因 URL 变化丢图。

### 6. 清理图片缓存

1. 打开更多 -> 数据与存储。
2. 查看图片缓存占用。
3. 点击清除图片缓存。
4. 回到漫画/小说书架。
5. 确认封面、标题、简介、标签仍存在。
6. 打开已读过但未下载的章节，允许重新联网加载图片。

### 7. 下载存储

1. 选择自定义存储目录。
2. 下载一部漫画。
3. 检查目录存在 `comics/<作品名>/meta.json/cover.jpg/*.cbz`。
4. 解压 CBZ，确认图片为 `001.jpg` 起。
5. 断网打开已下载漫画，确认可读。
6. 下载一部小说。
7. 检查 `novels/<作品名>/meta.json/chapters/*.json`。
8. 断网打开已下载小说，确认可读。

## 风险点与处理

### 1. 首次收藏同步请求太多

处理：

- 并发限制 2。
- 失败可恢复。
- 已补全的 tid 不重复请求。
- UI 可显示进度。

### 2. 标签资源未加载导致误判

处理：

- 公告用 `fid/typeid` 兜底。
- tagName 缺失时保存 typeid，后续资源加载成功可回填。

### 3. 自定义封面原路径失效

处理：

- 设置自定义封面时复制到 App 管理目录。
- 只保存复制后的路径。

### 4. 清理缓存误删重要文件

处理：

- 缓存清理只通过 `cached_images` 表中 `protected=0` 的记录执行。
- 不做危险的整目录递归删除。
- 下载存储目录永远不归图片缓存清理管。

### 5. 存储路径权限问题

处理：

- 选择目录后立即测试创建 `.nomedia` 和临时文件。
- 失败则不保存该路径，并提示用户。
- Android 默认 media 路径失败时降级到 App 外部/文档目录。

## 最终完成标准

- 标签/typeid 成为漫画、小说、收藏同步的统一事实来源。
- 收藏 Tab 成为漫画/小说模块的数据入口。
- 漫画/小说详情页展示自带标签和自定义标签。
- 图片缓存保存实体并能抵抗 URL 变化。
- 存储下载结构清晰，支持离线阅读。
- 更多页能管理缓存和存储，但不会误删受保护数据。
