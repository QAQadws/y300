```text
      presentation/
        thread_detail_state.dart

    auth/
      data/auth_repository.dart
      presentation/
        login_state.dart
        login_controller.dart
        login_page.dart

  shared/
    widgets/
      app_skeleton.dart
```

### 3.2 分层职责

1. `data` 层：只负责接口调用与 JSON 到模型的映射。
2. `presentation` 层：控制器负责状态流转，页面只负责渲染与交互。
3. `shared` 层：复用骨架组件，避免各页面重复造轮子。
4. `app` 层：应用入口、主题和初始路由。

### 3.3 关键解耦点

1. `ForumRepository` 与 `ForumDisplayRepository` 均使用抽象接口 + Discuz 实现，便于 Mock。
2. 分页页面（forumdisplay/viewthread）使用独立控制器和独立页面状态对象，避免 UI 直接耦合请求细节。
3. 登录页控制器只关心表单与提交状态，登录成功判定交由 `AuthRepository`。
4. 首页新增 `ForumHomeRepository` 聚合层，统一编排 `forumindex + profile + myfavforum`，控制器只做视图映射。
5. 聚合层对增强信息（profile/myfavforum）采用“失败降级”策略，不阻塞 forumindex 主流程。
6. 页面测试通过 Provider 覆盖仓库依赖，不依赖真实网络。

## 4. 页面说明

### 4.1 启动页/骨架页

文件：

1. `lib/features/startup/presentation/startup_page.dart`
2. `lib/shared/widgets/app_skeleton.dart`

行为：

1. 展示冷启动骨架，避免白屏。
2. 启动完成后进入论坛首页。

### 4.2 论坛首页（forumindex）

对应接口：

1. `module=forumindex`
2. `module=profile`
3. `module=myfavforum`

文件：

1. `lib/features/forum/data/forum_home_repository.dart`
1. `lib/features/forum/presentation/forum_home_controller.dart`
2. `lib/features/forum/presentation/forum_home_page.dart`

行为：

1. 未登录：仅展示 `forumindex` 分组版块。
2. 已登录：优先展示“我收藏的版块”（`myfavforum`），随后展示 `forumindex` 版块。
3. “我收藏的版块”复用统一 `_ForumCard` 渲染，保持 UI 组件复用。
4. 点击版块进入 forumdisplay 页。
5. 顶部提供登录页入口。

### 4.3 forumdisplay 页（帖子列表）

对应接口：

1. `module=forumdisplay&fid={fid}&page={page}`

文件：

1. `lib/features/forum/data/forum_display_repository.dart`
2. `lib/features/forum/data/models/forum_display_models.dart`
3. `lib/features/forum/presentation/forum_display_state.dart`
4. `lib/features/forum/presentation/forum_display_controller.dart`
5. `lib/features/forum/presentation/forum_display_page.dart`

行为：

1. 首屏加载当前版块帖子。
2. 支持下拉刷新。
3. 支持加载更多分页。
4. 点击帖子进入 viewthread 页。
5. 模型层兼容 `forum_threadlist/threadlist` 与 `tpp/perpage` 字段，避免接口字段差异导致列表空白。

### 4.4 viewthread 页（帖子详情）

对应接口：

1. `module=viewthread&tid={tid}&page={page}`

文件：

1. `lib/features/thread/presentation/thread_detail_state.dart`
2. `lib/features/thread/presentation/thread_detail_controller.dart`
3. `lib/features/thread/presentation/thread_detail_page.dart`

行为：

1. 展示楼层列表。
2. 支持分页加载更多回复。
3. 使用 Html 组件渲染 message 的富文本内容。
4. 将 `[attach]aid[/attach]` 占位替换为附件图片，未命中的图片追加到正文末尾。

### 4.5 登录页

文件：

1. `lib/features/auth/presentation/login_state.dart`
2. `lib/features/auth/presentation/login_controller.dart`
3. `lib/features/auth/presentation/login_page.dart`

行为：

1. 提供用户名密码输入。
2. 提交后显示 loading，避免重复提交。
3. 成功显示欢迎信息，失败展示错误文案。
4. 实际登录逻辑复用 `AuthRepository.login`（网页登录 + profile 校验）。

## 登录链路增强（稳定性与登录态校验）

### 改造目标

1. 解决登录偶发“卡住/超时”体验差的问题。
2. 登录成功后，不只依赖 profile，增加 forumindex 的 auth 字段校验。
3. 登录成功后立即刷新论坛首页数据，保证 UI 登录态及时更新。

### 主要实现

1. `AuthRepository` 新增 `verifyAuthByForumIndex()`：
   - 调用 `module=forumindex`。
   - 判断 `Variables.auth` 是否非空。
2. `AuthRepository.login()` 改为双重校验：
   - 网页登录成功后，先验证 `forumindex.auth`；
   - 再拉取 `profile` 生成 `SessionInfo`。
3. `LoginController.submit()` 增强：
   - 增加并发提交保护，避免重复点击造成链路堆叠；
   - 增加超时兜底（18秒），超时时给出明确错误文案；
   - `_current` 改为 `state.asData?.value ?? initial`，避免状态切换时空值歧义。
4. `LoginPage` 行为增强：
   - 登录成功后 `invalidate(forumHomeControllerProvider)` 触发首页刷新；
   - 成功提示后 `Navigator.pop(true)` 返回上一页。
