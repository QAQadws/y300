### 3.2 分层职责

1. `data` 层：只负责接口调用与 JSON 到模型的映射。
2. `presentation` 层：控制器负责状态流转，页面只负责渲染与交互。
3. `shared` 层：复用骨架组件，避免各页面重复造轮子。
4. `app` 层：应用入口、主题和初始路由。

### 3.3 关键解耦点

1. `ForumRepository` 与 `ForumDisplayRepository` 均使用抽象接口 + Discuz 实现，便于 Mock。
2. 分页页面（forumdisplay/viewthread）使用独立控制器和独立页面状态对象，避免 UI 直接耦合请求细节。
3. 登录页控制器只关心表单与提交状态，登录成功判定交由 `AuthRepository`。
4. 首页新增 `ForumHomeRepository` 聚合层，统一编排 `forumindex + profile + myfavforum`，控制器只做视图映射。
5. 聚合层对增强信息（profile/myfavforum）采用“失败降级”策略，不阻塞 forumindex 主流程。
6. 页面测试通过 Provider 覆盖仓库依赖，不依赖真实网络。
