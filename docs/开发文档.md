## 3. 架构与解耦说明

### 3.1 目录结构（新增部分）

```text
lib/
  app/
    y300_app.dart
  features/
    startup/
      presentation/
        startup_page.dart
    forum/
      data/
        forum_repository.dart
        models/forum_index_models.dart
      presentation/
        forum_home_state.dart
        forum_home_controller.dart
        forum_home_page.dart
  shared/
    widgets/
      app_skeleton.dart
  main.dart
```

### 3.2 分层职责

1. `data` 层
   - `ForumRepository` 只负责拿数据（已抽象为接口）。
   - `DiscuzForumRepository` 负责具体 Discuz 实现。
2. `presentation` 层
   - `ForumHomeController` 只做状态与映射，不关心 Dio 细节。
   - `ForumHomePage` 只做渲染与交互。
3. `shared` 层
   - 骨架组件在 `app_skeleton.dart` 复用，避免页面复制粘贴。
4. `app` 层
   - `Y300App` 负责应用入口配置（主题、初始页）。

### 3.3 关键解耦点

1. `ForumRepository` 改为抽象接口，页面测试可直接注入假仓库。
2. `forumRepositoryProvider` 对外暴露接口类型，不暴露具体实现。
3. 首页 UI 读取 `ForumHomeViewData`，不直接依赖后端原始 JSON 结构。
4. 启动页通过可选 `onCompleted` 回调提供测试注入点。

## 4. 页面说明

### 4.1 启动页/骨架页

文件：

1. `lib/features/startup/presentation/startup_page.dart`
2. `lib/shared/widgets/app_skeleton.dart`

行为：

1. 启动展示品牌标题和骨架占位。
2. 冷启动最短停留约 900ms，避免页面闪烁。
3. 自动跳转到论坛首页。

### 4.2 论坛首页（板块 + 列表）

文件：

1. `lib/features/forum/presentation/forum_home_controller.dart`
2. `lib/features/forum/presentation/forum_home_state.dart`
3. `lib/features/forum/presentation/forum_home_page.dart`

行为：

1. `ForumHomeController` 启动即拉取 `forumindex`。
2. 将分类与版块映射为分组展示。
3. 支持三态渲染：加载态骨架、失败态重试、成功态列表。
4. 支持下拉刷新。

## 5. 测试说明

### 5.1 测试文件

1. `test/features/startup/presentation/startup_page_test.dart`
2. `test/features/forum/presentation/forum_home_page_test.dart`
3. `test/widget_test.dart`
4. `test/features/auth/auth_repository_test.dart`（此前已实现）

### 5.2 覆盖场景

#### 启动页

1. 启动页可渲染品牌与骨架。
2. 到达时延后触发完成回调（用于替代真实跳转）。

#### 论坛首页

1. 加载中显示骨架。
2. 成功后显示分组与版块列表。
3. 首次失败后可点击“重试”并恢复成功列表。

#### 应用入口

1. 应用启动默认进入启动页。

### 5.3 如何运行测试

运行新增 MVP 页面测试：

```bash
flutter test test/features/startup/presentation/startup_page_test.dart
flutter test test/features/forum/presentation/forum_home_page_test.dart
```

运行全部测试：

```bash
flutter test
```

运行静态检查：

```bash
flutter analyze
```

### 5.4 预期结果

1. 测试命令输出 `All tests passed!`
2. 静态检查输出 `No issues found!`
