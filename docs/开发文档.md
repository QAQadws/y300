#### 连接到安卓模拟器
`adb connect 127.0.0.1:5555`

#### 安装依赖
添加如下依赖
```yaml
dependencies:
  json_annotation: ^4.9.0
  dio: ^5.9.2
  flutter_riverpod: ^3.3.1
  shared_preferences: ^2.5.5
  logger: ^2.7.0

dev_dependencies:
  build_runner: ^2.10.5
  json_serializable: ^6.10.0
```
执行`flutter pub get`
查看已安装的包`flutter pub deps`
